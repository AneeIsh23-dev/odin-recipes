# odin-recipes
This is my first project from The Odin Project.

The project is a basic recipe website built using HTML. It contains different recipe pages with ingredients, cooking steps, descriptions, and images.

What I Learned

While building this project, I practiced:

-Creating HTML pages and using HTML elements
-Creating links between different pages
-Adding images to web pages
-Using unordered and ordered lists
-Organizing files and folders
-Using the command line to navigate and -manage my project
-Using Git to track changes
-Creating commits with meaningful commit -messages
-Pushing my project to GitHub
-Technologies Used
-HTML
-Git
-GitHub
